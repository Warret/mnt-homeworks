# vector-role

Роль для установки и настройки агента сбора логов/метрик Vector.

## Требования
* Ubuntu/Debian

## Переменные роли

| Имя переменной | Описание | Значение по умолчанию |
|----------------|----------|-----------------------|
| `vector_version` | Версия Vector для установки | `"0.38.0"` |
| `vector_download_url` | Прямая ссылка на deb-пакет | `"https://..."` (см. defaults) |
| `vector_temp_path` | Путь для временного файла | `"/tmp/vector.deb"` |

## Пример использования
```yaml
- hosts: vector
  roles:
    - vector-role
