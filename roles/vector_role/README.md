# Роль vector_role
## Описание
Ansible-роль для установки и настройки агента сбора логов Vector (версия 0.38.0). 
Роль поддерживает кросс-платформенную установку на семейства ОС:

  Debian/Ubuntu (использует apt и .deb пакеты)
  RedHat/Rocky (использует yum/dnf и .rpm пакеты)

## Ход выполнения тестирования (Molecule + Tox)
Для обеспечения максимальной приближенности к production-среде тестирование выполняется на реальных виртуальных машинах в Яндекс Облаке с использованием драйвера default.
## Протестированные сценарии (Scenarios):

  ubuntu24 — тестирование на Ubuntu 24.04.
  rocky9 — тестирование на Rocky Linux 9.

## Этапы тестирования в каждом сценарии:

  Converge: Успешное применение роли (установка пакетов, деплой шаблона конфига, запуск сервиса).
  Idempotence: Подтверждение идемпотентности (повторный запуск не вносит изменений, changed=0).
  Verify: Проверка через assert-ы (наличие бинарного файла vector, корректный вывод версии, статус сервиса active, наличие файла конфигурации /etc/vector/vector.yaml).

## Необходимые файлы для запуска
В корне роли находятся все необходимые конфигурационные файлы:

  tox.ini — файл для автоматизированного запуска тестов в изолированных Python-окружениях.
  molecule/ubuntu24/ и molecule/rocky9/ — директории со сценариями Molecule (molecule.yml, converge.yml, verify.yml).

## Как запустить тесты

  Активируйте виртуальное окружение (если вы его используете):
  source ~/ansible-venv/bin/activate
  Убедитесь, что установлены необходимые зависимости:
  pip install tox molecule ansible
  Запустите полное тестирование через Tox (выполнит оба сценария):
  tox
  Альтернативно, можно запустить Molecule для конкретного сценария:
  molecule test -s ubuntu24
  molecule test -s rocky9

## Результаты
Все тесты проходят успешно. Общее время выполнения tox составляет около 150 секунд.
